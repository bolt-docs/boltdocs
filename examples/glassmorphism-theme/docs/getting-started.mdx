# Welcome to Glassmorphism

This is a demonstration of the **UI Customization** capabilities in Boltdocs. Everything you see here—from the headings to the cards—has been customized using `mdx-components.tsx` and a custom CSS theme.

## Core Features

Our theme is designed to be modern, fast, and beautiful.

## Code Customization

We've completely overhauled the code block component using `PrimitiveCodeBlock`. It now features a terminal-like header and a premium copy button.

```tsx
// Example of our custom glassmorphism configuration
export const theme = {
  glass: {
    blur: '12px',
    opacity: 0.4,
    border: 'rgba(255, 255, 255, 0.1)'
  }
}
```

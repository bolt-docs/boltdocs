# UI Customization Guide

Boltdocs is designed to be fully customizable. You can change everything from simple colors to complex component logic.

## CSS Variables

The easiest way to customize your site is by overriding CSS variables in your `index.css`.

```css
@theme {
  --color-primary-500: oklch(0.7 0.2 280);
}
```

## MDX Components

For more deep customization, use `mdx-components.tsx` to override HTML tags and register global components.

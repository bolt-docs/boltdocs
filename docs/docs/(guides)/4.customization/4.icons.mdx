# Icons & Sidebar Groups

Adding icons makes your documentation much easier to navigate and visually appealing. Boltdocs comes with [Lucide React](https://lucide.dev/) icons built-in, meaning you have access to hundreds of beautiful icons out of the box. 

You can assign these icons to any page or folder just by typing the exact name of the icon (for example, `Rocket` or `BookOpen`).

---

## 1. Adding Icons to Pages

To add an icon to a specific page, simply add the `icon` property to the frontmatter at the top of your `.mdx` file:

```mdx
---
title: "Quick Start"
icon: "Rocket"
---

# Quick Start
Your content goes here...
```

## 2. Adding Icons to Folders (Sidebar Groups)

When you group files inside a folder (like a `guides/` folder), it appears as a collapsible section in your sidebar. To give this folder a custom title and icon, the easiest way is to create an `index.mdx` file inside it.

<FileTree>
- docs/
  - guides/
    - index.mdx       # This controls the folder's appearance!
    - deployment.md
</FileTree>

Inside **`guides/index.mdx`**, just define the title and icon:

```mdx
---
title: "Platform Guides"
icon: "Library"
---

Welcome to the platform guides! 
(This file also acts as the landing page for the folder).
```

---

## 3. Global Sidebar Configuration

If you don't want to create an `index.mdx` file for every single folder, no worries! You can globally define your folder titles and icons directly in your `boltdocs.config.ts` file.

Just add a `sidebarGroups` section to your theme config. The keys should match your exact folder names (don't worry about any numbers you used for sorting, just use the clean name):

```tsx title="boltdocs.config.ts"
import { defineConfig } from 'boltdocs/config'

export default defineConfig({
  theme: {
    sidebarGroups: {
      "guides": {
        title: "Platform Guides",
        icon: "Library"
      },
      "api": {
        title: "API Reference",
        icon: "Code"
      }
    }
  }
})
```

<Tip>
Using the global config keeps your workspace clean if you don't actually need a landing page for those folders!
</Tip>

## 4. Using Your Own Custom Icons

Want to use your company's logo or a custom SVG instead of the built-in Lucide icons? It's super easy.

1. Create a file named `icons.tsx` right inside your `docs` folder.
2. Export your SVG icons as standard React components.

```tsx title="docs/icons.tsx"
import React from 'react'

export const CustomDiscord = () => (
  <svg width="24" height="24" viewBox="0 0 24 24" fill="currentColor">
    {/* your SVG paths go here */}
  </svg>
)

export const CustomBrandIcon = () => (
  <svg>...</svg>
)
```

That's it! Boltdocs will automatically detect this file. You can now use your custom icons anywhere in your markdown files or config just by calling their export name:

```mdx
---
title: "Join our Community"
icon: "CustomDiscord"
---

Come chat with us!
```

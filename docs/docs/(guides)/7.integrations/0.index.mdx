# Integrations

Boltdocs supports integrations with third-party services to help you understand your audience, improve search, and extend functionality.

## Choosing a Solution
 
| Approach | Best For |
| :--- | :--- |
| **Built-in Integrations** | Quick setup for Google Analytics or Google Tag Manager via config. |
| **Analytics Plugin API** | Programmatic tracking, custom events, and accessing data in components. |
| **Custom Plugins** | Extending the build pipeline, MDX transformations, or major features. |

### Integration (Config)

Use `boltdocs.config.ts` for simple integrations:

```ts
export default defineConfig({
  integrations: {
    ga4: { measurementId: 'G-XXXXXXXXXX' }
  }
})
```

Best for: Basic tracking that doesn't need custom code.

### Plugin (@bdocs/plugin-analytics)

Use the package when you need programmatic access:

```tsx
import { useAnalytics } from 'boltdocs/client'

function MyComponent() {
  const analytics = useAnalytics()

  return <button onClick={() => analytics.trackEvent({ action: 'click' })}>
    Track me
  </button>
}
```

Best for: Custom events, analytics in your own components, fine-grained control.

### Plugin System

Use the full plugin system for major extensions:

```ts
export default createPlugin({
  name: 'my-plugin',
  permissions: ['mdx:remark'],
  remarkPlugins: [myPlugin]
})
```

Best for: New MDX components, build pipeline extensions, complex integrations.


<Note>
For most documentation sites, the built-in GA4 integration is sufficient. You get page views, search tracking, and file downloads automatically — no extra code needed.
</Note>

## Configuration Reference

All integrations are configured in `boltdocs.config.ts`:

```ts
export default defineConfig({
  // ... other config
  integrations: {
    // Google Analytics 4
    ga4: {
      measurementId: 'G-XXXXXXXXXX',
      debug?: boolean,
      anonymizeIp?: boolean,
      sendPageView?: boolean,
      cookieFlags?: string
    },
    // Google Tag Manager
    gtm: {
      tagId: 'GTM-XXXXXXX',
      dataLayerName?: string,
      preview?: string
    }
  }
})
```

See the individual integration guides for all available options.

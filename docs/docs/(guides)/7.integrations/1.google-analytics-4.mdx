# Google Analytics 4 (GA4)

Google Analytics 4 is Google's next-generation analytics platform. Boltdocs makes it dead simple to integrate — just add your Measurement ID and you're ready to track.

## How it works

Boltdocs automatically injects the official `gtag.js` script into every page. Once configured, you'll see:

- **Page views** — Track which pages users visit
- **Search interactions** — When users search your documentation
- **Downloads** — Files users download from your docs
- **External links** — Links to other websites

All of this happens automatically. No extra code needed.

## Quick Setup

```ts title="boltdocs.config.ts"
import { defineConfig } from 'boltdocs'

export default defineConfig({
  siteUrl: 'https://your-docs.com',
  integrations: {
    ga4: {
      measurementId: 'G-XXXXXXXXXX'
    }
  }
})
```

Find your Measurement ID in your [GA4 Admin panel](https://analytics.google.com/) under "Data Streams" → your website → "Measurement ID".

## Configuration Options

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `measurementId` | `string` | **required** | Your GA4 Measurement ID (starts with `G-`) |
| `debug` | `boolean` | `false` | Enable tracking in development mode |
| `anonymizeIp` | `boolean` | `false` | Anonymize user IP addresses |
| `sendPageView` | `boolean` | `true` | Send page views automatically |
| `cookieFlags` | `string` | `undefined` | Custom cookie flags |

### Example: Full Configuration

```ts title="boltdocs.config.ts"
integrations: {
  ga4: {
    measurementId: 'G-XXXXXXXXXX',
    anonymizeIp: true,        // GDPR-friendly
    sendPageView: true,
    debug: process.env.NODE_ENV !== 'production'
  }
}
```

## Tracking in Development

By default, GA4 only activates during production builds. This prevents polluting your analytics with test data.

To test locally:

```ts title="boltdocs.config.ts"
integrations: {
  ga4: {
    measurementId: 'G-XXXXXXXXXX',
    debug: true // Remove for production!
  }
}
```

<Warning>
Don't forget to remove `debug: true` before deploying to production. Your analytics will be flooded with fake data.

The recommended approach is to use environment variables:

```ts title="boltdocs.config.ts"
integrations: {
  ga4: {
    measurementId: process.env.GA4_MEASUREMENT_ID,
    debug: process.env.NODE_ENV !== 'production'
  }
}
```
</Warning>

## Auto-Tracked Events

Once configured, Boltdocs automatically tracks these events:

| Event | Trigger |
|-------|---------|
| `page_view` | User navigates to a new page |
| `search` | User searches your docs |
| `file_download` | User clicks a downloadable file |
| `external_link` | User clicks a link to another site |

### Custom Events

You can track custom events from your React components:

```tsx
import { useTrackEvent } from 'boltdocs/client'

function DocsCTA() {
  const trackEvent = useTrackEvent()

  return (
    <button onClick={() => {
      trackEvent({
        action: 'click',
        category: 'conversion',
        label: 'docs-signup'
      })
    }}>
      Get Started
    </button>
  )
}
```

## Privacy & Compliance

For GDPR compliance or if privacy is a concern:

```ts title="boltdocs.config.ts"
integrations: {
  ga4: {
    measurementId: 'G-XXXXXXXXXX',
    anonymizeIp: true        // Masks the last octet of IP addresses
  }
}
```

<Note>
Consider adding a cookie consent banner if you operate in the EU. GA4 requires explicit user consent for non-essential cookies in many jurisdictions.

Boltdocs doesn't include a built-in cookie consent system — you can add one using the plugin system if needed.
</Note>

## Troubleshooting

**Analytics not showing up?**
1. Check your Measurement ID is correct
2. Make sure you ran a production build (`pnpm run build`)
3. Check the Network tab in DevTools — you should see a request to `google-analytics.com`

**Too much test data?**
1. Add `debug: false` or remove it
2. Use GA4's "Exclude filter" to filter test hits in your view settings

**Need to track custom pages?**
Use `useTrackPageView()`:

```tsx
import { useTrackPageView } from 'boltdocs/client'

function CustomPage() {
  const trackPage = useTrackPageView()

  useEffect(() => {
    trackPage('/custom-page', 'Custom Documentation Page')
  }, [])

  return <div>...</div>
}
```

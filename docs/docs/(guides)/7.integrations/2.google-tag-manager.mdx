# Google Tag Manager (GTM)

Google Tag Manager is a tag management system that lets you install and manage tracking tools without touching your code. Perfect for teams that need multiple tracking tools, or when you want non-technical folks to manage tags.

## How it works

GTM acts as a container. You install one snippet in your docs, then manage all your tracking tools from the GTM dashboard:

```
┌────────────────────────────────────────────────────┐
│  Your Docs                    GTM Dashboard        │
│  ┌──────────┐                 ┌──────────────┐   │
│  │ GTM      │ ◄─── tags ─── │ GA4          │   │
│  │ Container│               │ Facebook Pixel│   │
│  └──────────┘               │ Hotjar      │   │
│                           │ Custom Tags │   │
│                           └──────────────┘   │
└────────────────────────────────────────────────────┘
```

## Quick Setup

```ts title="boltdocs.config.ts"
import { defineConfig } from 'boltdocs'

export default defineConfig({
  siteUrl: 'https://your-docs.com',
  integrations: {
    gtm: {
      tagId: 'GTM-XXXXXXX'
    }
  }
})
```

Find your Container ID in your [GTM dashboard](https://tagmanager.google.com/) under "Account" → "Container" → "Container ID".

## Configuration Options

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `tagId` | `string` | **required** | Your GTM Container ID (starts with `GTM-`) |
| `dataLayerName` | `string` | `'dataLayer'` | Custom name for the data layer |
| `preview` | `string` | `undefined` | Enable GTM preview mode |

### Example: Custom Data Layer

```ts title="boltdocs.config.ts"
integrations: {
  gtm: {
    tagId: 'GTM-XXXXXXX',
    dataLayerName: 'myDataLayer'
  }
}
```

### Example: Preview Mode

Preview mode lets you test tags before publishing:

```ts title="boltdocs.config.ts"
integrations: {
  gtm: {
    tagId: 'GTM-XXXXXXX',
    preview: 'env-1' // Check your GTM dashboard for the preview value
  }
}
```

<Warning>
Remove preview mode before going to production! Preview mode can cause unexpected tag firing.

```ts title="boltdocs.config.ts"
integrations: {
  gtm: {
    tagId: 'GTM-XXXXXXX',
    preview: process.env.NODE_ENV === 'development' ? 'env-1' : undefined
  }
}
```
</Warning>


## Using GTM with Custom Events

Once GTM is configured, you can push custom events to the data layer:

```tsx
import { useAnalytics } from 'boltdocs/client'

function SignupButton() {
  const analytics = useAnalytics()

  return (
    <button onClick={() => {
      // This pushes to window.dataLayer
      analytics.trackEvent({
        action: 'signup',
        category: 'conversion',
        label: 'docs-trial'
      })
    }}>
      Start Free Trial
    </button>
  )
}
```

Then in GTM, create a trigger for the `custom_event` with the name `signup` to fire your conversion tag.

## Installing Tags in GTM

After setting up Boltdocs with GTM:

1. Go to your [GTM dashboard](https://tagmanager.google.com/)
2. Create a new tag (e.g., GA4, Facebook Pixel)
3. Set up triggers (e.g., "All Page Views", "Custom Event")
4. Preview your container
5. Test on your docs
6. Publish when ready

<Tip>
GTM has a built-in preview mode. Click "Preview" in your GTM dashboard, then visit your docs. You'll see which tags fire for each interaction. This is the best way to debug your setup.
</Tip>

## Common GTM Setups

### Google Analytics 4 through GTM

1. In GTM, create a **GA4 Configuration** tag
2. Set your Measurement ID
3. Create a trigger: "All Page Views"
4. Publish and test

This approach gives you GTM's flexibility with GA4's simplicity.

### Facebook Pixel

1. In GTM, create a **Custom HTML** tag
2. Paste the Facebook Pixel base code
3. Create a trigger for Page Views
4. Create another trigger for your conversion event

### Multiple Tools

GTM shines when you need multiple tools. Create one GTM container:

- Google Analytics 4
- Facebook Pixel
- Twitter Conversion Pixel
- Hotjar
- Custom event listeners

All managed from one dashboard, no code changes needed.

## Troubleshooting

**Tags not firing?**
1. Check your Container ID is correct
2. Verify triggers match your events
3. Use GTM's debug preview mode
4. Check the Console for dataLayer errors

**Data not appearing in reports?**
1. Wait 24-48 hours (GA4 can be slow)
2. Check your trigger conditions
3. Verify the tag is published (not just saved)

**Too much test data?**
Use GTM's built-in "Exclude test hits" option, or create a filter in GA4 to exclude your IP.

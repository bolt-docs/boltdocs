# Custom Themes

Boltdocs styling is built with **Tailwind CSS v4** and a customizable CSS custom properties system. While the framework ships with a default premium "Neutral" theme, you can construct a completely bespoke visual experience by using the framework's standalone layout reset stylesheet and overriding design tokens.

---

## The Styling Architecture

Boltdocs exposes two styling entry points you can import in your project's main `index.css`:

1. **`boltdocs/theme/neutral.css`**: The default theme bundle. It resets spacing, styles default HTML elements, configures Shiki code block wrappers, and defines the terracotta orange/warm-neutral color theme variables.
2. **`boltdocs/theme/reset.css`**: A layout reset stylesheet. It resets container dimensions, prevents mobile text overflow, configures scrolling margins for heading anchors, styles scrollbars, and configures Shiki highlighting states, but **defines no color palettes or fonts**.

To build a custom theme, you should import `boltdocs/theme/reset.css` instead of the default theme, and define your own variables under Tailwind's `@theme` directive.

---

## Step-by-Step Custom Theme

Follow these steps to set up a personalized styling theme for your documentation portal:

### Step 1: Update your stylesheet
Open your project's root `index.css` (or wherever your main style bundle is processed) and replace the default import with the framework's reset sheet:

```css title="index.css"
@import "tailwindcss";

/* 1. Import the Boltdocs layout reset to clear margins and configure Shiki styles */
@import "boltdocs/theme/reset.css";

/* 2. Configure Tailwind to scan Boltdocs component sources */
@source "./node_modules/boltdocs/dist";
```

### Step 2: Declare your theme overrides
Directly beneath your imports, declare your custom theme variables within the `@theme` directive. Here is a custom "Forest Green" palette template:

```css title="index.css"
@theme {
  /* Set custom brand fonts */
  --font-sans: "Outfit", "system-ui", sans-serif;
  --font-mono: "Fira Code", monospace;

  /* Custom Primary Accent (Forest Green) */
  --color-primary-50: #f0fdf4;
  --color-primary-100: #dcfce7;
  --color-primary-200: #bbf7d0;
  --color-primary-300: #86efac;
  --color-primary-400: #4ade80;
  --color-primary-500: #22c55e; /* Target color */
  --color-primary-600: #16a34a;
  --color-primary-700: #15803d;
  --color-primary-800: #166534;
  --color-primary-900: #14532d;

  /* Custom Neutrals (Cool slate dark/light backgrounds) */
  --color-neutral-50: #f8fafc;  /* Main light background */
  --color-neutral-100: #f1f5f9; /* Card light background */
  --color-neutral-200: #e2e8f0; /* Soft borders */
  --color-neutral-800: #0f172a; /* Body text color */
  --color-neutral-900: #020617; /* Slate dark main background */
  --color-neutral-950: #010409;
}
```

## Design Tokens Reference

Below is a reference of CSS custom properties utilized by the framework's layout primitives that you can override:

### Visual Colors

| Custom Property | Default value | Purpose |
| :--- | :--- | :--- |
| **`--color-primary-500`** | `#eb5828` | Main branding focus color (buttons, active link states, focus rings). |
| **`--color-neutral-50`** | `#faf9f5` | Page background color in Light mode. |
| **`--color-neutral-900`** | `#141413` | Page background color in Dark mode. |
| **`--color-neutral-800`** | `#25241d` | Body paragraph text color in Light mode. |

### Rounded Radii

You can customize the sharpness of buttons, input fields, popovers, and cards by redefining Tailwind border-radius variables:

```css
@theme {
  /* Make all UI components square */
  --radius-sm: 0px;
  --radius-md: 0px;
  --radius-lg: 0px;
  --radius-xl: 0px;
  --radius-2xl: 0px;
}
```

## Code Highlight Customization

By default, Shiki inherits theme styles defined in the configuration (`boltdocs.config.ts`). You can override line highlight indicators and code text styles in your stylesheet:

```css title="index.css"
/* Change the line highlight sidebar indicator color */
pre span.shiki-line-highlight::after {
  border-left-color: var(--color-primary-500) !important;
  background-color: color-mix(in srgb, var(--color-primary-500) 8%, transparent) !important;
}
```

# Tabs

The `Tabs` primitive provides a highly accessible, flexible foundation for organizing content into tabbed views. It handles all necessary ARIA attributes (`role="tablist"`, `role="tab"`, etc.) and keyboard navigation under the hood while giving you absolute control over styling and layout.

While Boltdocs provides a high-level `<Tabs>` component for standard MDX use, these primitives allow you to build customized tab experiences in your custom layouts or bespoke pages.

---

## Architecture

The Tabs primitive is designed as a compound component split into several sub-components:

```tsx
import { PrimitiveTabs } from 'boltdocs/client'
```

---

## API Reference

### PrimitiveTabs.Root
The top-level container component. By default, it acts as a standard wrapper with full-width.

### PrimitiveTabs.List
The container for tab triggers. It implements `role="tablist"` and manages horizontal scrolling and bottom borders.

### PrimitiveTabs.Item
The individual tab trigger button. It automatically toggles active states and styles.

<Field name="id" type="string" required>
  A unique identifier for this tab item.
</Field>

<Field name="selected" type="boolean" defaultValue="false">
  Indicates whether this specific tab is currently active.
</Field>

<Field name="disabled" type="boolean" defaultValue="false">
  Disables interaction for this tab trigger.
</Field>

<Field name="onClick" type="() => void">
  Callback for click interactions.
</Field>

### PrimitiveTabs.Content
The panel containing the active tab's inner content.

### PrimitiveTabs.Indicator
An optional sliding active indicator line positioned at the bottom of the active tab.

<Field name="style" type="React.CSSProperties">
  Used to pass inline style properties (like `width` and `transform`) for smooth transitions.
</Field>

## Example Usage

Here is how you can assemble these primitives to build a custom tab switcher with custom indicators:

```tsx
import { useState } from 'react'
import { PrimitiveTabs } from 'boltdocs/client'

function CustomTabSwitcher() {
  const [activeTab, setActiveTab] = useState('react')

  return (
    <PrimitiveTabs>
      <PrimitiveTabs.List>
        <PrimitiveTabs.Item 
          id="react" 
          selected={activeTab === 'react'} 
          onClick={() => setActiveTab('react')}
        >
          React
        </PrimitiveTabs.Item>
        <PrimitiveTabs.Item 
          id="vue" 
          selected={activeTab === 'vue'} 
          onClick={() => setActiveTab('vue')}
        >
          Vue
        </PrimitiveTabs.Item>
        
        {/* Dynamic bottom indicator */}
        <PrimitiveTabs.Indicator />
      </PrimitiveTabs.List>

      <PrimitiveTabs.Content>
        {activeTab === 'react' && <p>React is a library for building user interfaces.</p>}
        {activeTab === 'vue' && <p>Vue is an approachable and performant framework.</p>}
      </PrimitiveTabs.Content>
    </PrimitiveTabs>
  )
}
```

<Tip>
  When using `PrimitiveTabs.Item`, you do not need to manage the `role="tab"` attribute yourself—the component applies it automatically.
</Tip>

# Code Block

The `CodeBlock` primitive provides the foundational building blocks for displaying code snippets. It handles the container styling (borders, background), header layout, and content area (including truncation logic).

While Boltdocs provides a high-level `CodeBlock` component for MDX, these primitives allow you to build completely custom code block experiences in your layouts or custom components.

---

## Architecture

The Code Block is split into a root container and several sub-components that manage specific areas of the block.

```tsx
import { PrimitiveCodeBlock } from 'boltdocs/client'
```

---

## API Reference

### PrimitiveCodeBlock.Root
The main container for the code block. It manages the background color and optional borders.

<Field name="plain" type="boolean" defaultValue="false">
  If `true`, removes the default borders and margins. Useful for embedding code blocks inside other containers like Cards.
</Field>

<Field name="className" type="string">
  Override default styles.
</Field>

### PrimitiveCodeBlock.Header
A container for the top section of the code block. Usually holds the file title, language icon, and action buttons (like Copy).

### PrimitiveCodeBlock.Group
A small helper primitive that uses Flexbox to group items together in the header (e.g., an icon next to a filename).

### PrimitiveCodeBlock.Content
The main area where the code is displayed. It wraps your `<pre>` or `<code>` elements.

<Field name="shouldTruncate" type="boolean" defaultValue="false">
  If `true`, applies a `max-height` to the content and prepares it for an "Expand" interaction.
</Field>

---

## Example Usage

You can assemble these primitives to create a custom code block with a custom header.

```tsx
import { PrimitiveCodeBlock } from 'boltdocs/client'

function CustomBlock({ code, filename, lang }) {
  return (
    <PrimitiveCodeBlock>
      <PrimitiveCodeBlock.Header>
        <PrimitiveCodeBlock.Group>
          <span className="opacity-50">{lang}</span>
          <span className="font-bold">{filename}</span>
        </PrimitiveCodeBlock.Group>
        
        <button className="text-xs hover:text-white">
          Custom Action
        </button>
      </PrimitiveCodeBlock.Header>

      <PrimitiveCodeBlock.Content>
        <pre className="p-4 overflow-x-auto">
          <code>{code}</code>
        </pre>
      </PrimitiveCodeBlock.Content>
    </PrimitiveCodeBlock>
  )
}
```

<Tip>
  When using `PrimitiveCodeBlock.Content`, the component automatically applies styles to any direct child `<pre>` element if `shouldTruncate` is enabled.
</Tip>

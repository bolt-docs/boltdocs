## Entry points

| Import | Runtime | Use it for |
| :--- | :--- | :--- |
| `boltdocs` | Node / build | `defineConfig`, plugins, config types, JSON-LD factories. |
| `boltdocs/client` | Browser / SSR | React hooks, structured data, transitions, collections, and client utilities. |
| `boltdocs/primitives` | Browser / SSR | Unstyled layout, navigation, link, and interaction components. |

## React hooks

The [Hooks reference](/docs/api/hooks/use-config) documents the public hooks individually:

- `useConfig`, `useTheme`, `useI18n`, `useVersion`, and `useLocation`
- `useRoutes`, `useSearch`, `useNavbar`, `usePageNav`, and `useTabs`
- collection hooks such as `usePosts`, `usePost`, and `useRecentPosts`

## Plugin API

The [Plugin API](/docs/api/plugin-api) is split into focused references for lifecycle hooks, caches, diagnostics, paths, virtual modules, middleware, server, and HMR.

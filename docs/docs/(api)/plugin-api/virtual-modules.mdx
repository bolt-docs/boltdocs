# `ctx.virtualModules` — PluginVirtualModulesAPI

Declares virtual modules that Vite resolves and loads without touching
the file system. Each plugin calls `add()` from `beforeBuild`
or `beforeDev`.

```ts
ctx.virtualModules.add(
  'virtual:my-plugin/theme.css',
  () => `:root { --primary: #6366f1; }`,
)

ctx.virtualModules.has('virtual:my-plugin/theme.css')
// → boolean

const todos: readonly RegisteredVirtualModule[] = ctx.virtualModules.list()
```

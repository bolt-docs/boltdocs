Boltdocs plugins extend the core through hooks into remark, rehype, Vite, and the client registry. Install them with pnpm and register them in `plugins` inside `boltdocs.config.ts`:

```bash
pnpm add @bdocs/plugin-mermaid
```

```ts title="boltdocs.config.ts"
import { defineConfig } from 'boltdocs'
import mermaidPlugin from '@bdocs/plugin-mermaid'

export default defineConfig({
  plugins: [mermaidPlugin()],
})
```

## Writing your own

To build a plugin, see the [Plugin API reference](/docs/api/plugin-api) and the [plugin authoring guide](/docs/api/plugin-api#putting-it-all-together). Run `boltdocs audit` before adding any third-party plugin to scan it for risky calls.

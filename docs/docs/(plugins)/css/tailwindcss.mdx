The `@bdocs/plugin-tailwindcss` plugin provides official integration for **Tailwind CSS v4** in Boltdocs via `@tailwindcss/vite`.

## Installation

Install `@bdocs/plugin-tailwindcss` and `tailwindcss`:

```bash
pnpm add -D @bdocs/plugin-tailwindcss tailwindcss
```


## Usage in CSS

In your CSS file (e.g., `docs/index.css`), add the Tailwind v4 directive:

```css
@import "tailwindcss";

@theme {
  --color-brand: #2563eb;
}
```

Now utility classes like `bg-brand`, `text-slate-900`, `dark:bg-slate-950`, `flex`, and `grid` are ready to use in your MDX pages and components!

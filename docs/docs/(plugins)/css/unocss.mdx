The `@bdocs/plugin-unocss` plugin provides official integration for **UnoCSS** in Boltdocs via `@unocss/vite`.

## Installation

Install `@bdocs/plugin-unocss` and `unocss`:

```bash
pnpm add -D @bdocs/plugin-unocss unocss
```


## Usage

Import `virtual:uno.css` in your layout or main style:

```tsx
import 'virtual:uno.css'
```

The plugin automatically scans the Boltdocs `docs/` directory for utilities in `.md` and `.mdx` sources. You can customize the source directory or use any UnoCSS Vite mode:

```ts
unocssPlugin({
  docsDir: 'content/docs',
  mode: 'global',
})
```

Set `scanDocs: false` when the documentation sources should not be scanned automatically.

El componente `Sidebar` muestra la estructura de directorios del sitio, listando carpetas anidadas, rutas de páginas, encabezados de categorías y etiquetas de navegación.

La primitiva `Sidebar` es **neutra de estilo**: aporta estructura, accesibilidad (ARIA), comportamiento (restauración de scroll, autoapertura del grupo activo, scroll hasta el elemento activo) y un conjunto de atributos de estado `data-*`. **Cada decisión visual pertenece a tu tema** — colores, espaciados, bordes, tratamientos activo/hover. Estiliza los estados con variantes de Tailwind v4 (`data-active:bg-primary-500/10`) o CSS puro (`[data-active] { ... }`).

## Ejemplo de Sidebar Componible

Construye una barra lateral personalizada responsiva usando los contenedores primitivos y el hook de enrutamiento automático:

```tsx
// docs/components/CustomSidebar.tsx
import { Sidebar } from 'boltdocs/primitives'
import { useRoutes } from 'boltdocs/client'

export default function CustomSidebar() {
  const { routes } = useRoutes()

  return (
    <>
      {/* 1. Contenedor de escritorio */}
      <Sidebar className="hidden lg:flex flex-col w-sidebar sticky top-navbar h-[calc(100vh-var(--spacing-navbar))] border-r border-subtle bg-main">
        <Sidebar.Header className="px-4 py-3 flex items-center justify-between border-b border-subtle">
          <span className="text-xs font-bold uppercase tracking-wider text-muted">Navegación</span>
        </Sidebar.Header>
        <Sidebar.Content className="flex-1 overflow-y-auto p-4 flex flex-col gap-6">
          {/* Los elementos activos se exponen vía data-active; estilízalos en tu tema. */}
          <Sidebar.Items
            routes={routes}
            classNames={{
              item: 'rounded-md px-2.5 py-1.5 text-sm transition-colors text-muted hover:bg-surface hover:text-body data-active:bg-primary-500/10 data-active:text-primary-500 data-active:font-medium',
              groupHeader: 'px-2 mb-2 text-xs font-bold uppercase tracking-widest text-muted/50',
              groupContent: 'flex flex-col gap-0.5',
              subgroupContent: 'ml-4 pl-3 border-l border-subtle/50 mt-0.5 flex flex-col gap-0.5',
            }}
          />
        </Sidebar.Content>
      </Sidebar>

      {/* 2. Cajón móvil responsivo */}
      <Sidebar.Mobile
        overlayClassName="fixed inset-0 z-50 bg-black/20 backdrop-blur-sm lg:hidden"
        className="fixed top-0 left-0 bottom-0 w-80 bg-main border-r border-subtle shadow-2xl outline-none"
      >
        <Sidebar.Header className="px-4 py-3 flex items-center justify-between border-b border-subtle">
          <span className="text-xs font-bold uppercase tracking-wider text-muted">Menú</span>
        </Sidebar.Header>
        <Sidebar.Content className="flex-1 overflow-y-auto p-4 flex flex-col gap-6">
          <Sidebar.Items routes={routes} />
        </Sidebar.Content>
      </Sidebar.Mobile>
    </>
  )
}
```

## Referencia de Producción Real

A continuación se muestra una implementación de referencia completa y lista para producción que demuestra cómo construir un sistema de navegación lateral con todas las funciones (similar al tema integrado). Integra el logo, controles de cierre móviles, estructuras de escritorio vs. móvil y combina selectores de versión e idioma dentro del cajón móvil:

```tsx
// docs/components/ProductionSidebar.tsx
import { Sidebar, Button, Menu } from 'boltdocs/primitives'
import { useRoutes, useNavbar, useUI, useVersion, useI18n } from 'boltdocs/client'
import { X, ChevronDown, Languages } from 'lucide-react'

export default function ProductionSidebar() {
  const { routes, config } = useRoutes()
  const { logo, title, logoProps } = useNavbar()
  const { closeSidebar } = useUI()

  const { currentVersionLabel, availableVersions, handleVersionChange } = useVersion()
  const { currentLocale, availableLocales, handleLocaleChange } = useI18n()

  const SidebarLogo = logo ? (
    <img
      src={logo}
      alt={logoProps?.alt || title}
      width={24}
      height={24}
      className="rounded-lg"
    />
  ) : null

  // 1. Selector de versión para móvil
  const MobileVersionSelector = availableVersions.length > 0 && (
    <select
      value={availableVersions.find(v => v.isCurrent)?.value}
      onChange={(e) => handleVersionChange(e.target.value)}
      className="flex-1 bg-surface border border-subtle rounded-lg px-3 py-2 text-xs font-semibold"
    >
      {availableVersions.map(v => (
        <option key={v.key} value={v.value}>{v.label}</option>
      ))}
    </select>
  )

  // 2. Selector de idioma para móvil
  const MobileLocaleSelector = availableLocales.length > 0 && (
    <select
      value={currentLocale}
      onChange={(e) => handleLocaleChange(e.target.value)}
      className="flex-1 bg-surface border border-subtle rounded-lg px-3 py-2 text-xs font-semibold"
    >
      {availableLocales.map(loc => (
        <option key={loc.key} value={loc.value}>{loc.label}</option>
      ))}
    </select>
  )

  const hasMobileSelectors = availableVersions.length > 0 || availableLocales.length > 0

  return (
    <>
      {/* A. Panel de escritorio */}
      <Sidebar className="hidden lg:flex flex-col w-sidebar sticky top-navbar h-[calc(100vh-var(--spacing-navbar))] border-r border-subtle bg-main">
        <Sidebar.Content className="flex-1 overflow-y-auto p-4 flex flex-col gap-6">
          <Sidebar.Items
            routes={routes}
            classNames={{
              item: 'rounded-md px-2.5 py-1.5 text-sm transition-colors text-muted hover:bg-surface hover:text-body data-active:bg-primary-500/10 data-active:text-primary-500',
            }}
          />
        </Sidebar.Content>
      </Sidebar>

      {/* B. Cajón móvil */}
      <Sidebar.Mobile
        overlayClassName="fixed inset-0 z-50 bg-black/20 backdrop-blur-sm lg:hidden"
        className="fixed top-0 left-0 bottom-0 w-80 bg-main border-r border-subtle shadow-2xl outline-none"
      >
        <Sidebar.Header className="flex items-center justify-between border-b border-subtle px-4 py-3">
          <div className="flex items-center gap-3">
            {SidebarLogo}
            <span className="font-bold text-base text-body truncate max-w-[140px]">
              {title}
            </span>
          </div>

          <Button
            onPress={closeSidebar}
            className="h-8 w-8 flex items-center justify-center text-muted hover:text-body rounded-lg hover:bg-surface transition-colors"
          >
            <X size={18} />
          </Button>
        </Sidebar.Header>

        <Sidebar.Content className="flex-1 overflow-y-auto p-4 flex flex-col gap-6">
          {/* Selectores de versión/idioma dentro del cajón móvil */}
          {hasMobileSelectors && (
            <div className="flex flex-col gap-3 mb-6">
              <div className="flex gap-2">
                {MobileVersionSelector}
                {MobileLocaleSelector}
              </div>
              <div className="border-b border-subtle my-2" />
            </div>
          )}

          <Sidebar.Items routes={routes} />
        </Sidebar.Content>
      </Sidebar.Mobile>
    </>
  )
}
```

## Atributos de Estado (`data-*`)

Las primitivas de `Sidebar` exponen su estado exclusivamente a través de atributos `data-*`. **Solo están presentes cuando son verdaderos**, por lo que el CSS basado en presencia funciona directamente. Decide tus propios colores (`primary`, `secondary`, `success`, ...) desde CSS — la primitiva nunca pinta nada por sí misma.

| Atributo | Se Emite En | Presente Cuando |
| :--- | :--- | :--- |
| **`data-active`** | enlace `Sidebar.Link`, contenedor `Sidebar.Group` | El enlace / grupo contiene la ruta actual |
| **`data-open`** | botón de grupo colapsable + chevron, toggle de `Sidebar.SubGroup` + chevron | La sección está expandida |
| **`data-collapsible`** | contenedor `Sidebar.Group` | El grupo renderiza un botón de alternancia |
| **`data-depth`** | enlace `Sidebar.Link` | Profundidad de anidado (número) |
| **`data-badge`** | span de insignia | Texto / tipo de la insignia (p. ej. `new`, `updated`, `deprecated`) |
| **`aria-current`** | enlace `Sidebar.Link` | `"page"` cuando está activo |
| **`aria-expanded`** | botones de alternancia | `"true"` / `"false"` |

Estilizando el elemento activo desde tu tema — Tailwind v4:

```tsx
<Sidebar.Items
  routes={routes}
  classNames={{
    item: 'rounded-md px-2.5 py-1.5 text-sm transition-colors text-muted hover:bg-soft hover:text-body data-active:bg-primary-500/10 data-active:text-primary-400',
  }}
/>
```

O CSS puro:

```css
[data-sidebar-root] a[data-active] {
  color: var(--color-primary-400);
  background: color-mix(in srgb, var(--color-primary-500) 10%, transparent);
}
```

Los iconos renderizados dentro de un enlace heredan `currentColor`, por lo que colorear el enlace colorea el icono automáticamente — sin clases de estado por icono.

| Componente | Etiqueta HTML | Descripción | Props |

## Slots (`classNames`)

`Sidebar.Items` acepta un mapa `classNames` que se mezcla sobre los defaults de la primitiva con `tailwind-merge`, por lo que tus overrides ganan sin marcadores `!`. Cada clave corresponde a una pieza del árbol automatizado. Los defaults son **solo estructurales** — el layout y los estados son tuyos para estilizar:

| Clave | Se Aplica A | Default |
| :--- | :--- | :--- |
| **`item`** | raíz del enlace hoja | `group flex items-center gap-2.5 outline-none` |
| **`itemIcon`** | icono del enlace hoja | `shrink-0` |
| **`itemLabel`** | etiqueta del enlace hoja | `truncate` |
| **`group`** | envoltorio del grupo | `undefined` |
| **`groupHeader`** | encabezado del grupo (botón o título) | `undefined` |
| **`groupIcon`** | icono inicial del grupo | `undefined` |
| **`groupTitle`** | envoltorio del título del grupo | `flex items-center gap-2` |
| **`groupContent`** | envoltorio de hijos del grupo | `flex flex-col` |
| **`subgroup`** | envoltorio del subgrupo | `flex flex-col` |
| **`subgroupLink`** | enlace del subgrupo | `flex-1 pr-8` |
| **`subgroupContent`** | envoltorio de hijos del subgrupo | `flex flex-col` |
| **`toggle`** | alternancia expandir/colapsar del subgrupo | `absolute right-1` |

```tsx
<Sidebar.Items
  routes={routes}
  classNames={{
    item: 'rounded-md px-2.5 py-1.5 text-sm transition-colors text-muted hover:bg-soft hover:text-body data-active:bg-primary-500/10 data-active:text-primary-400',
    groupHeader: 'px-2 mb-2 text-xs font-bold uppercase tracking-widest text-muted/60',
    toggle: 'size-7 rounded-md hover:bg-soft',
  }}
/>
```

## Render Props

`componentItem` y `componentGroup` son reemplazos estructurales: cuando se proveen, la pieza por defecto no se renderiza en absoluto, dándote control total del markup (por ejemplo, envoltorios de navegación personalizados o iconos por ruta).

| Render Prop | Props Recibidas |
| :--- | :--- |
| **`componentItem`** | `{ route, activePath, activeRoute, isActive, depth }` |
| **`componentGroup`** | `{ group, isGroupActive, children }` |

```tsx
<Sidebar.Items
  routes={routes}
  componentItem={({ route, isActive, depth }) => (
    <CustomLink active={isActive} depth={depth} route={route} />
  )}
  componentGroup={({ group, isGroupActive, children }) => (
    <nav aria-label={group.title}>
      <h2>{group.title}</h2>
      {children}
    </nav>
  )}
/>
```

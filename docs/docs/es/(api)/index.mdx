---

## Descripción General de la Arquitectura

Boltdocs divide sus módulos en puntos de entrada separados para aislar las configuraciones del lado del servidor de los elementos interactivos del lado del navegador:

| Importación del Módulo | Propósito | Entorno |
| :--- | :--- | :--- |
| **`boltdocs`** | Esquemas de configuración del proyecto y plugins | Node / Build |
| **`boltdocs/client`** | Componentes React con estilos predeterminados, hooks de contexto y asistentes | Browser / SSR |
| **`boltdocs/primitives`** | Elementos primitivos sin estilos para crear diseños personalizados | Browser / SSR |

## Exportaciones de Tipos

Importa las interfaces de TypeScript directamente desde `'boltdocs'` (para esquemas de configuración) o `'boltdocs/client'` (para elementos de enrutamiento del lado del cliente):

### Tipos de Configuración de Build
```ts
import type { BoltdocsConfig, BoltdocsPlugin } from 'boltdocs'
```

### Tipos de Contexto del Cliente
```ts
import type { RouteMeta, SidebarGroup, Heading } from 'boltdocs/client'
```

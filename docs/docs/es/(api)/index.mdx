## Entrypoints

| Import | Runtime | Úsalo para |
| :--- | :--- | :--- |
| `boltdocs` | Node / build | `defineConfig`, plugins, tipos de configuración y factories JSON-LD. |
| `boltdocs/client` | Browser / SSR | Hooks React, structured data, transiciones, colecciones y utilidades cliente. |
| `boltdocs/primitives` | Browser / SSR | Componentes sin estilos de layout, navegación, enlaces e interacción. |

## Hooks de React

La [referencia de Hooks](/docs/es/api/hooks/use-config) documenta cada hook público:

- `useConfig`, `useTheme`, `useI18n`, `useVersion` y `useLocation`
- `useRoutes`, `useSearch`, `useNavbar`, `usePageNav` y `useTabs`
- Hooks de colecciones como `usePosts`, `usePost` y `useRecentPosts`

## API de Plugins

La [API de Plugins](/docs/es/api/plugin-api) se divide en referencias de lifecycle hooks, caches, diagnostics, paths, virtual modules, middleware, server y HMR.

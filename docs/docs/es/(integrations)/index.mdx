Boltdocs se integra con servicios populares y ofrece funciones integradas para búsqueda, localización, versionado y SEO. Esta sección cubre todas las integraciones disponibles.


## Funciones Integradas

### Búsqueda integrada

Boltdocs incluye búsqueda de texto completo sin dependencias. El índice de búsqueda se construye en tiempo de compilación y se incrusta en el paquete del cliente. Sin claves de API, sin servicios externos.

- **Indexación:** Títulos, encabezados, descripciones, texto del cuerpo
- **Activación:** `Cmd+K` / `Ctrl+K` o haz clic en el botón de búsqueda
- **Personalización:** Usa el hook `useSearch()` o el componente `<SearchDialog>`

### Internacionalización

Enrutamiento basado en locales usando convenciones de carpetas. Soporta idiomas RTL, respaldos automáticos para páginas no traducidas y temáticas específicas por locale.

- **Configuración:** `i18n.defaultLocale`, `i18n.locales`
- **Estructura de carpetas:** `docs/es/`, `docs/fr/`
- **Soporte RTL:** Configura `direction: 'rtl'` en la configuración del locale

### Versionado

Mantén múltiples versiones de documentación (v1, v2, etc.) en paralelo. Cada versión es una carpeta en la raíz de `docs/`.

- **Configuración:** `versions.defaultVersion`, `versions.versions`
- **Estructura de carpetas:** `docs/v1/`, `docs/v2/`
- **Selector de versión:** Integrado en el diseño predeterminado

### SEO y Robots

Generación automática de etiquetas meta, imágenes Open Graph, sitemap.xml y robots.txt. Control detallado por página mediante frontmatter.

- **Configuración:** `seo`, `robots`, `siteUrl`
- **Auto-generado:** `sitemap.xml`, `robots.txt`
- **Por página:** Override mediante campo `seo` en frontmatter

### Colecciones

Agrupa archivos en directorios dinámicos usando convenciones de carpetas. Boltdocs mapea automáticamente las carpetas entre corchetes (por ejemplo `[blog]`) a rutas de colección, permitiendo listados personalizados, vistas de publicaciones y diseños aislados.

- **Convenciones:** `layout.tsx`, `list.tsx`, `post.tsx`
- **Cargadores de Datos:** Los datos tipados del cargador de colección están disponibles mediante `useLoaderData()`

## Servicios Externos

### Google Analytics 4

Rastrea vistas de página y eventos personalizados. Configura mediante `integrations.ga4` en tu configuración:

```ts
integrations: {
  ga4: {
    measurementId: 'G-XXXXXXXXXX',
  },
}
```

Las vistas de página se rastrean automáticamente. Usa el hook `useTrackEvent()` para eventos personalizados.

## Referencia de Configuración

| Clave | Tipo | Descripción |
| :--- | :--- | :--- |
| **`integrations.ga4`** | `GA4Config` | Configuración de Google Analytics 4 |
| **`integrations.feedback`** | `FeedbackConfig` | Configuración de la integración de retroalimentación personalizada |
| **`i18n`** | `I18nConfig` | Configuración de internacionalización |
| **`versions`** | `VersionsConfig` | Configuración de versionado |
| **`seo`** | `SeoConfig` | Valores predeterminados globales de SEO |
| **`robots`** | `RobotsConfig` | Configuración de robots.txt |
| **`siteUrl`** | `string` | Requerido para URLs absolutas en sitemap/og:image |

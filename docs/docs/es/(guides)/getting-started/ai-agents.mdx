Cada asistente IA es tan inteligente como el contexto que le des. Ya sea que uses **Cursor**, **Claude Code**, **GitHub Copilot** o **Gemini Code Assist**, nuestra skill estructurada le enseña a tu herramienta cómo funciona Boltdocs internamente — para que deje de adivinar y empiece a generar código que encaje con tu proyecto.

La skill es un conjunto de archivos markdown que actúan como una base de conocimiento localizada. Las herramientas IA los leen para aprender sobre `boltdocs.config.ts`, enrutamiento por sistema de archivos, componentes MDX incorporados y el sistema de estilos Tailwind CSS v4.

---

## Qué Contiene

La skill está organizada en un archivo de entrada principal y cuatro guías de referencia enfocadas. Cada guía cubre un área del framework para que la IA solo cargue lo que necesita:

| Archivo | Qué le Enseña a la IA |
| :--- | :--- |
| [`SKILL.md`](https://github.com/jesus-alcala/boltdocs/blob/develop/skills/boltdocs/SKILL.md) | Cuándo activar la skill — editando configuración, agregando páginas de docs, escribiendo componentes MDX o cambiando estilos. |
| [`configuration.md`](https://github.com/jesus-alcala/boltdocs/blob/develop/skills/boltdocs/references/configuration.md) | Escribir y mantener `boltdocs.config.ts` — `defineConfig`, metadatos del sitio, tema, plugins y estructura de pestañas. |
| [`routing.md`](https://github.com/jesus-alcala/boltdocs/blob/develop/skills/boltdocs/references/routing.md) | Enrutamiento por sistema de archivos dentro de `docs/`, grupos del sidebar, configuración de carpetas `meta.json` y alineación de pestañas. |
| [`components.md`](https://github.com/jesus-alcala/boltdocs/blob/develop/skills/boltdocs/references/components.md) | Componentes MDX incorporados (Callout, Cards, Mermaid), títulos de bloques de código, ecuaciones matemáticas e inyección global de componentes a través de `mdx-components.tsx`. |
| [`styling.md`](https://github.com/jesus-alcala/boltdocs/blob/develop/skills/boltdocs/references/styling.md) | Tokens de tema de Tailwind CSS v4, mapeos de colores semánticos, sobreescripciones de modo oscuro y sintaxis de variantes personalizadas segura para Biome. |

## Instalación

Incluimos un script de instalación automatizado `install-ai-agents.sh` en la raíz del proyecto. Copia los archivos de skill a la carpeta que tu entorno de IA espera.

### Instalación Rápida (Independiente)

Si estás agregando la skill a un proyecto Boltdocs existente sin clonar el repositorio del framework:

```bash
curl -fsSL https://raw.githubusercontent.com/jesus-alcala/boltdocs/develop/install-ai-agents.sh | bash
```

El script detecta si existen archivos de skill locales. Si no existen, los descarga de GitHub automáticamente.

### Instalación desde un Repositorio Clonado

Si tienes el repositorio de Boltdocs clonado, ejecuta el script directamente — usa los archivos locales para que la skill siempre coincida con tu checkout:

```bash
./install-ai-agents.sh
```

<Callout variant="tip" title="Consejo Profesional">
  Ejecuta el instalador desde el **directorio raíz de tu proyecto**, no desde el directorio del framework Boltdocs. La bandera `--output-dir` te permite apuntar a cualquier ubicación.
</Callout>

---

## Referencia del Script

El instalador soporta estas banderas para flujos automatizados o de CI:

| Bandera | Valor | Descripción |
| :--- | :--- | :--- |
| `-t, --target` | `cursor`, `claude`, `copilot`, `agents`, `all` | Qué editor o entorno de IA configurar. |
| `-o, --output-dir` | `<path>` | Directorio de instalación personalizado (sobreescribe las rutas por defecto). |
| `-y, --yes` | — | Modo no interactivo — salta los prompts y confirma automáticamente. |
| `-h, --help` | — | Imprime información de uso y sale. |

### Directorios de Destino por Defecto

| Destino | Ruta de Instalación |
| :--- | :--- |
| `cursor` | `.cursor/skills/boltdocs/` |
| `claude` | `.claude/skills/boltdocs/` |
| `copilot` | `.copilot/skills/boltdocs/` |
| `agents` (Gemini) | `.agents/skills/boltdocs/` |

### Ejemplo: Instalar para Claude en CI

```bash
./install-ai-agents.sh --target claude --yes
```

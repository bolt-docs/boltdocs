## Lo logramos: Boltdocs 3.3.0 supera a Docusaurus Faster

Nos propusimos construir el framework de documentación más rápido del ecosistema JavaScript. Hoy, con **Boltdocs 3.3.0**, nos enorgullece anunciar que Boltdocs supera oficialmente a **Docusaurus Faster** tanto en velocidad de **Cold Build** como en tiempo de **Dev Server Startup**.

<Callout type="info">
  En benchmarks comparativos sobre un sitio de 100 páginas:
  - **Velocidad de Cold Build**: **11.41s** vs Docusaurus **15.26s** (**3.85s / 34% más rápido**)
  - **Arranque del Dev Server**: **4.31s** vs Docusaurus **4.52s** (**210ms más rápido**)
  - **HMR Incremental MDX**: **0.36s** (**7x más rápido**)
</Callout>

## Cómo lo Conseguimos: Bajo el Capó

### 1. Precompilación Asíncrona Anticipada con Sätteri
En lugar de esperar al hook `buildStart()` de Vite para compilar los ASTs de Markdown, Sätteri ahora inicia la precompilación en los workers de Rust dentro de `configResolved()`. Esto permite que los hilos compilen archivos MDX en paralelo mientras Vite inicializa su grafo de plugins.

### 2. Dimensionamiento Dinámico de Pools en Piscina y Sätteri
En lugar de instanciar 7 workers fijos (lo que causaba contención de CPU y sobrecarga de IPC), el número de workers ahora se escala dinámicamente (`Math.min(cpus, Math.ceil(files/25))`), utilizando 4 workers óptimos para 100 páginas.

### 3. Arranque de Dev Server No Bloqueante y Rutas Perezosas
`generateRoutes()` ya no bloquea `server.listen()`. El servidor de desarrollo comienza a escuchar inmediatamente y genera el árbol de rutas en segundo plano antes de que el navegador realice su primera petición HTTP.

## 🎨 Core Agnóstico a Frameworks CSS y Plugins Oficiales

Antes de 3.3.0, el core tenía validaciones estáticas de Tailwind. En 3.3.0, **Boltdocs es 100% Agnóstico a Frameworks CSS**:

1. **Core Nativo Vanilla CSS**: Soporte por defecto para archivos `.css`, CSS Modules y variables CSS nativas sin dependencias externas. `base-theme.css` ofrece tokens de diseño base para componentes `ui-base`.
2. **API de Plugins Ampliada**: Los plugins ahora pueden registrar plugins de PostCSS y preprocesadores mediante `css: { postcssPlugins, preprocessorOptions }`.
3. **Nuevos Plugins Oficiales de Estilos**:
   - 🎨 **`@bdocs/plugin-tailwindcss`**: Soporte completo para Tailwind CSS v4 mediante `@tailwindcss/vite`.
   - ⚡ **`@bdocs/plugin-sass`**: Soporte para el preprocesador SASS / SCSS.
   - 🚀 **`@bdocs/plugin-unocss`**: Soporte para el motor atómico UnoCSS.

## Actualización a 3.3.0

Actualiza los paquetes en tu proyecto:

```bash
pnpm add boltdocs@latest @bdocs/ssg@latest
```

Si usas Tailwind CSS v4, simplemente añade `@bdocs/plugin-tailwindcss`:

```ts
// boltdocs.config.ts
import { defineConfig } from 'boltdocs'
import tailwindcssPlugin from '@bdocs/plugin-tailwindcss'

export default defineConfig({
  plugins: [
    tailwindcssPlugin(),
  ],
})
```

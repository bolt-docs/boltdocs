Los plugins de Boltdocs extienden el core mediante hooks en remark, rehype, Vite y el registro de client. Instálalos con pnpm y regístralos en `plugins` dentro de `boltdocs.config.ts`:

```bash
pnpm add @bdocs/plugin-mermaid
```

```ts title="boltdocs.config.ts"
import { defineConfig } from 'boltdocs'
import mermaidPlugin from '@bdocs/plugin-mermaid'

export default defineConfig({
  plugins: [mermaidPlugin()],
})
```

## Escribir tu propio plugin

Para construir un plugin, consulta la [referencia de la API de plugins](/docs/api/plugin-api) y la [guía de autoría de plugins](/docs/api/plugin-api#putting-it-all-together). Ejecuta `boltdocs audit` antes de añadir cualquier plugin de terceros para escanearlo en busca de llamadas de riesgo.

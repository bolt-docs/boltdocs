# Vanilla CSS en Boltdocs

Boltdocs es **100% Agnóstico a Frameworks de CSS** por diseño. El núcleo soporta de forma nativa archivos **Vanilla CSS** y **CSS Modules** sin necesidad de configuración ni plugins externos.

## Características

- 🎨 **Vanilla CSS Sin Configuración**: Importa cualquier archivo `.css` en tus componentes o layout.
- 📦 **CSS Modules**: Soporte completo para estilos encapsulados `[nombre].module.css`.
- 🌙 **Tokens de Tema Nativos**: Variables `:root` y tokens de tema oscuro `[data-theme='dark']` / `.dark` incluidos en `base-theme.css`.
- ⚡ **Extremadamente Rápido**: Potenciado por la empaquetación nativa de CSS de Vite y PostCSS.

---

## Uso Básico

Importa tu archivo CSS en tu layout personalizado (`docs/layout.tsx`) o componentes:

```tsx
// docs/layout.tsx
import './style.css'

export default function Layout({ children }: { children: React.ReactNode }) {
  return <div className="custom-container">{children}</div>
}
```

### Ejemplo de CSS Modules

```css
/* boton.module.css */
.primaryButton {
  background-color: var(--bdocs-primary);
  color: #ffffff;
  padding: 0.5rem 1rem;
  border-radius: 0.375rem;
  border: none;
  cursor: pointer;
  transition: background-color 0.2s ease;
}

.primaryButton:hover {
  background-color: var(--bdocs-primary-hover);
}
```

```tsx
// CustomButton.tsx
import styles from './boton.module.css'

export function CustomButton({ children }: { children: React.ReactNode }) {
  return <button className={styles.primaryButton}>{children}</button>
}
```

## Variables CSS Base

Boltdocs incluye variables CSS estándar en `base-theme.css`:

```css
:root {
  --bdocs-font-family: system-ui, sans-serif;
  --bdocs-font-mono: ui-monospace, monospace;

  --bdocs-bg: #ffffff;
  --bdocs-bg-secondary: #f8fafc;
  --bdocs-text: #0f172a;
  --bdocs-text-muted: #64748b;
  --bdocs-border: #e2e8f0;
  --bdocs-primary: #2563eb;
  --bdocs-primary-hover: #1d4ed8;
}

[data-theme='dark'],
.dark {
  --bdocs-bg: #0b0f19;
  --bdocs-bg-secondary: #111827;
  --bdocs-text: #f8fafc;
  --bdocs-text-muted: #94a3b8;
  --bdocs-border: #1e293b;
  --bdocs-primary: #3b82f6;
  --bdocs-primary-hover: #60a5fa;
}
```

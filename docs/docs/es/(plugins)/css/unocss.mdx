El plugin `@bdocs/plugin-unocss` proporciona integración oficial para **UnoCSS** en Boltdocs mediante `@unocss/vite`.

## Instalación

Instala `@bdocs/plugin-unocss` y `unocss`:

```bash
pnpm add -D @bdocs/plugin-unocss unocss
```


## Uso

Importa `virtual:uno.css` en tu layout o estilo principal:

```tsx
import 'virtual:uno.css'
```

El plugin escanea automáticamente el directorio `docs/` de Boltdocs para encontrar utilidades en fuentes `.md` y `.mdx`. Puedes personalizar el directorio o utilizar cualquier modo de Vite de UnoCSS:

```ts
unocssPlugin({
  docsDir: 'content/docs',
  mode: 'global',
})
```

Usa `scanDocs: false` si las fuentes de documentación no deben escanearse automáticamente.

Todas las utilidades se importan del paquete `boltdocs`:

```ts
import {
  // Visitors
  visitNodes,
  visitMdxElements,
  visitRehypeElements,
  visitRemarkHeadings,
  visitRemarkLinks,

  // Builders
  createMdxElement,
  createMdxAttribute,
  createRehypeElement,

  // Properties
  setNodeProperty,
  getNodeProperty,
  addNodeClass,
  removeNodeClass,
  hasNodeClass,

  // Constants & Symbols
  MDX_NODES,
  SKIP,
  EXIT,
} from 'boltdocs'
```

## Visitantes del AST

### `visitNodes(tree, test, callback)`

Un wrapper de tipo seguro alrededor de `unist-util-visit` para recorrer el AST.

```ts
function visitNodes<T extends Node>(
  tree: Node,
  test: string | string[] | ((node: Node) => boolean),
  callback: (node: T, index: number, parent: Parent) => void | symbol,
): void
```

| Parámetro | Tipo | Descripción |
| :--- | :--- | :--- |
| **`tree`** | `Node` | El nodo raíz del AST a recorrer. |
| **`test`** | `string \| string[] \| (node) => boolean` | Una cadena de tipo de nodo, arreglo de tipos, o función predicado para filtrar nodos. |
| **`callback`** | `(node, index, parent) => void` | Se llama por cada nodo coincidente. Retorna `SKIP` o `EXIT` para controlar el recorrido. |

**Ejemplo:** Reemplaza bloques de código con un componente personalizado:

```ts
import { visitNodes, createMdxElement, SKIP, MDX_NODES } from 'boltdocs'

visitNodes(tree, MDX_NODES.CODE, (node, index, parent) => {
  if (node.lang !== 'custom') return
  parent.children[index] = createMdxElement('CustomBlock', {
    value: node.value,
  }, [], true)
  return SKIP
})
```

### `visitMdxElements(tree, name, callback)`

Visita elementos JSX MDX (tanto elementos de flujo como de texto) que coincidan con un nombre de componente.

```ts
function visitMdxElements(
  tree: Node,
  name: string | string[],
  callback: (node: MdxJsxElement, index: number, parent: Parent) => void | symbol,
): void
```

**Ejemplo:** Encuentra todos los componentes `Note` en el árbol:

```ts
visitMdxElements(tree, 'Note', (node, index, parent) => {
  console.log('Found <Note> at index', index)
})
```

### `visitRehypeElements(tree, tagName, callback)`

Visita nodos de elementos HTML de rehype que coincidan con un nombre de etiqueta.

```ts
function visitRehypeElements(
  tree: Node,
  tagName: string,
  callback: (node: ElementNode, index: number, parent: Parent) => void | symbol,
): void
```

**Ejemplo:** Transforma todos los elementos `pre`:

```ts
visitRehypeElements(tree, 'pre', (node, index, parent) => {
  node.properties = { ...node.properties, class: 'code-block' }
})
```

### `visitRemarkHeadings(tree, callback)`

Visita todos los nodos de encabezado en el AST de remark.

```ts
function visitRemarkHeadings(
  tree: Node,
  callback: (node: any, index: number, parent: Parent) => void | symbol,
): void
```

**Ejemplo:** Genera una tabla de contenidos:

```ts
const headings: string[] = []
visitRemarkHeadings(tree, (node) => {
  const text = node.children?.map((c: any) => c.value).join('')
  headings.push(text)
})
```

### `visitRemarkLinks(tree, callback)`

Visita todos los nodos de enlace en el AST de remark.

```ts
function visitRemarkLinks(
  tree: Node,
  callback: (node: any, index: number, parent: Parent) => void | symbol,
): void
```

**Ejemplo:** Recopila todos los enlaces externos:

```ts
visitRemarkLinks(tree, (node) => {
  if (node.url?.startsWith('http')) {
    console.log('External link:', node.url)
  }
})
```

## Constructores del AST

### `createMdxElement(name, attributes?, children?, isFlow?)`

Crea un nodo de elemento JSX MDX. Esta es la forma principal de inyectar componentes React personalizados en el AST de MDX.

```ts
function createMdxElement(
  name: string,
  attributes?: Record<string, unknown>,
  children?: Node[],
  isFlow?: boolean,
): MdxJsxElement
```

| Parámetro | Tipo | Predeterminado | Descripción |
| :--- | :--- | :--- | :--- |
| **`name`** | `string` | — | El nombre del componente React (por ejemplo, `'Math'`, `'Mermaid'`). |
| **`attributes`** | `Record<string, unknown>` | `{}` | Props del componente. Los objetos se convierten en `mdxJsxAttributeValueExpression`. |
| **`children`** | `Node[]` | `[]` | Nodos hijos del AST. |
| **`isFlow`** | `boolean` | `true` | `true` para nivel de bloque (`mdxJsxFlowElement`), `false` para en línea (`mdxJsxTextElement`). |

**Ejemplo:** Crea un componente `<Math>` en línea:

```ts
createMdxElement('Math', {}, [{ type: 'text', value: 'E = mc^2' }], false)
// → { type: 'mdxJsxTextElement', name: 'Math', attributes: [], children: [...] }
```

**Ejemplo:** Crea un componente de bloque con atributos:

```ts
createMdxElement('Mermaid', {
  chart: 'graph TD; A-->B',
  config: { theme: 'dark' },
}, [], true)
```

### `createMdxAttribute(name, value)`

Crea un solo nodo de atributo JSX MDX.

```ts
function createMdxAttribute(name: string, value: unknown): MdxJsxAttribute
```

Si `value` es un objeto, se envuelve como un `MdxJsxAttributeValueExpression`. De lo contrario, se convierte a cadena.

### `createRehypeElement(tagName, properties?, children?)`

Crea un nodo de elemento HTML de rehype para el árbol HAST.

```ts
function createRehypeElement(
  tagName: string,
  properties?: Record<string, unknown>,
  children?: Node[],
): ElementNode
```

**Ejemplo:** Crea un `<div class="wrapper">`:

```ts
createRehypeElement('div', { class: 'wrapper' }, [
  { type: 'text', value: 'content' },
])
```

## Propiedades de Nodos

### `setNodeProperty(node, key, value)`

Establece una propiedad HTML en un nodo mediante `node.data.hProperties`.

```ts
function setNodeProperty(node: NodeWithHProperties, key: string, value: unknown): void
```

**Ejemplo:** Añade una clase CSS a un bloque de código:

```ts
setNodeProperty(node, 'class', 'highlighted')
```

### `getNodeProperty(node, key)`

Lee una propiedad HTML de `node.data.hProperties`.

```ts
function getNodeProperty(node: NodeWithHProperties, key: string): unknown
```

### `addNodeClass(node, className)`

Añade un nombre de clase CSS a un nodo de elemento rehype.

```ts
function addNodeClass(node: ElementNode, className: string): void
```

Maneja tanto la representación de cadena como de arreglo de `properties.className`.

### `removeNodeClass(node, className)`

Elimina una clase CSS de un nodo de elemento rehype.

```ts
function removeNodeClass(node: ElementNode, className: string): void
```

### `hasNodeClass(node, className)`

Verifica si un nodo de elemento rehype tiene una clase CSS específica.

```ts
function hasNodeClass(node: ElementNode, className: string): boolean
```

## Constantes y Símbolos

### `MDX_NODES`

Un mapa constante de todas las cadenas de tipo de nodo MDX y MDAST. Usa estas en lugar de cadenas crudas para beneficiarte del chequeo de tipos y la seguridad en renombramientos.

```ts
const MDX_NODES = {
  ROOT: 'root',
  ELEMENT: 'element',
  TEXT: 'text',
  CODE: 'code',
  INLINE_CODE: 'inlineCode',
  HEADING: 'heading',
  PARAGRAPH: 'paragraph',
  LINK: 'link',
  IMAGE: 'image',
  LIST: 'list',
  LIST_ITEM: 'listItem',
  JSX_FLOW_ELEMENT: 'mdxJsxFlowElement',
  JSX_TEXT_ELEMENT: 'mdxJsxTextElement',
  JSX_ATTRIBUTE: 'mdxJsxAttribute',
  FLOW_EXPRESSION: 'mdxFlowExpression',
  TEXT_EXPRESSION: 'mdxTextExpression',
  ESM: 'mdxjsEsm',
} as const
```

**Ejemplo:**

```ts
visitNodes(tree, MDX_NODES.CODE, callback)
// en lugar de
visitNodes(tree, 'code', callback)
```

### `SKIP` y `EXIT`

Símbolos de control reexportados de `unist-util-visit` para gestionar el flujo del recorrido.

| Símbolo | Efecto |
| :--- | :--- |
| **`SKIP`** | Impide visitar los hijos del nodo actual. |
| **`EXIT`** | Detiene inmediatamente el recorrido de todo el árbol. |

**Ejemplo:**

```ts
import { visitNodes, SKIP, EXIT, MDX_NODES } from 'boltdocs'

visitNodes(tree, MDX_NODES.CODE, (node, index, parent) => {
  if (node.lang === 'ignore') return SKIP  // don't visit children
  if (node.value.includes('STOP')) return EXIT  // stop entirely
})
```

## Preguntas Frecuentes

### ¿Puedo importar `unist-util-visit` directamente en lugar de usar `visitNodes`?

Sí, pero `visitNodes` proporciona genéricos de tipo seguro, filtrado de tipos basado en arreglos y un manejo consistente de `SKIP`/`EXIT`. Prefiérelo sobre la biblioteca cruda para el desarrollo de plugins de Boltdocs.

### ¿Necesito manejar `mdxJsxFlowElement` y `mdxJsxTextElement` por separado?

Cuando usas `visitMdxElements`, ambos tipos se verifican automáticamente. Si usas `visitNodes` directamente, pasa ambos tipos:

```ts
visitNodes(tree, [MDX_NODES.JSX_FLOW_ELEMENT, MDX_NODES.JSX_TEXT_ELEMENT], callback)
```

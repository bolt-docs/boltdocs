El historial oficial de versiones de Boltdocs. Esta página concentra la línea de tiempo de releases; cada post contiene el anuncio completo, el contexto técnico y las notas de actualización.

<Timeline>
  <Timeline.Item date="2026-07-28" title="Boltdocs 3.3.0" badge="Minor">
    Arranque y builds más rápidos, un core agnóstico a CSS, integraciones oficiales para Tailwind CSS, SASS y UnoCSS, y una API de plugins tipada más completa. También incorpora datos estructurados (JSON-LD), View Transitions, file-routing literal de `pages-external` y publicaciones de colecciones ordenadas de más nuevas a más antiguas. Lee el [post de la versión 3.3.0](/docs/es/blog/boltdocs-3.3.0).
  </Timeline.Item>

  <Timeline.Item date="2026-07-12" title="Boltdocs 3.2.0" badge={{ text: 'Minor', variant: 'minor' }}>
    Los warm builds se vuelven mucho más rápidos gracias al salto del build del servidor y a comprobaciones más ligeras del hash del cliente. La versión agrega syntax highlighting con WASM, procesamiento paralelo de CSS crítico, tiempos por etapa del pipeline, el paquete independiente `@bdocs/unist-utils` y el componente MDX `Timeline`. Lee el [post de la versión 3.2.0](/docs/es/blog/boltdocs-3.2.0).
  </Timeline.Item>

  <Timeline.Item date="2026-06-26" title="Boltdocs 3.1.0" badge={{ text: 'Minor', variant: 'minor' }}>
    Project Nitro comienza con el pipeline experimental `--turbo`, compilación MDX con Sätteri, extracción de CSS crítico con Zig/WASM, parsing de un solo paso, feature flags, drafts, hooks de colecciones, soporte para PostHog y correcciones importantes de build, routing, SEO y HMR. Lee el [post de la versión 3.1.0](/docs/es/blog/boltdocs-3.1.0).
  </Timeline.Item>

  <Timeline.Item date="2026-06-22" title="Boltdocs 3.0.0" badge={{ text: 'Major', variant: 'major' }}>
    La línea 3.x comienza con el parser nativo basado en Zig, integraciones reorganizadas, Vercel Analytics y Speed Insights, comentarios con Giscus, feedback personalizado, la renovación de Ask AI y una amplia actualización de SEO y UI. Lee el [post de la versión 3.0.0](/docs/es/blog/boltdocs-3.0.0).
  </Timeline.Item>
</Timeline>

The official Boltdocs release history. This page keeps the version timeline in one place; each release post contains the longer announcement, implementation context, and upgrade notes.

<Timeline>
  <Timeline.Item date="2026-07-28" title="Boltdocs 3.3.0" badge="Minor">
    Faster startup and builds, a CSS-agnostic core, official Tailwind CSS, SASS, and UnoCSS integrations, and an expanded typed plugin API. This release also adds opt-in structured data (JSON-LD), View Transitions, literal `pages-external` file routing, and newest-first collection posts. Read the [3.3.0 release post](/docs/blog/boltdocs-3.3.0).
  </Timeline.Item>

  <Timeline.Item date="2026-07-12" title="Boltdocs 3.2.0" badge={{ text: 'Minor', variant: 'minor' }}>
    Warm builds become substantially faster through the server-build skip and lighter client hash checks. The release adds WASM-powered syntax highlighting, parallel critical CSS processing, per-step pipeline timing, the standalone `@bdocs/unist-utils` package, and the `Timeline` MDX component. Read the [3.2.0 release post](/docs/blog/boltdocs-3.2.0).
  </Timeline.Item>

  <Timeline.Item date="2026-06-26" title="Boltdocs 3.1.0" badge={{ text: 'Minor', variant: 'minor' }}>
    Project Nitro begins with the experimental `--turbo` pipeline, Sätteri MDX compilation, Zig/WASM critical CSS extraction, single-pass parsing, feature flags, drafts, collection hooks, PostHog support, and important build, routing, SEO, and HMR fixes. Read the [3.1.0 release post](/docs/blog/boltdocs-3.1.0).
  </Timeline.Item>

  <Timeline.Item date="2026-06-22" title="Boltdocs 3.0.0" badge={{ text: 'Major', variant: 'major' }}>
    The 3.x line starts with the Zig-powered native parser, reorganized integrations, Vercel Analytics and Speed Insights, Giscus comments, custom feedback, the Ask AI overhaul, and a broad SEO and UI refresh. Read the [3.0.0 release post](/docs/blog/boltdocs-3.0.0).
  </Timeline.Item>
</Timeline>

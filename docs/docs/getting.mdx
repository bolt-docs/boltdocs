# Potenciando tu Documentación con MDX

Boltdocs viene equipado con un conjunto de componentes interactivos y primitivas listas para usar. No es necesario importar nada; estos componentes están disponibles globalmente en cualquier archivo `.mdx` para que puedas centrarte únicamente en escribir contenido espectacular.

---

## 1. Llamadas de Atención (Callouts)

Las llamadas de atención son perfectas para destacar notas, advertencias, consejos o peligros en tu documentación. Puedes usar el componente base `<Callout>` o los atajos semánticos integrados.

### Atajos Integrados

<Note>
  **Nota informativa**: Este es un mensaje para dar contexto adicional al lector. Ideal para aclaraciones menores.
</Note>

<Tip>
  **Consejo práctico**: Puedes usar imágenes con soporte de tema para que tu interfaz se adapte automáticamente al modo claro y oscuro del usuario.
</Tip>

<Warning>
  **Advertencia**: Asegúrate de tener instalada la versión de `pnpm` recomendada antes de inicializar el proyecto.
</Warning>

<Danger>
  **Peligro / Error**: Modificar archivos dentro de la carpeta `.turbo` directamente puede corromper el estado de caché de tu compilación.
</Danger>

<Info>
  **Información**: Boltdocs compila tus archivos MDX a un bundle ultraliviano utilizando Vite bajo el capó.
</Info>

### Componente `<Callout>` Personalizado

Si quieres definir un título específico o usar una variante en particular, puedes usar la etiqueta `<Callout>` directamente:

```mdx
<Callout variant="tip" title="¡Truco de Rendimiento!">
  Usa `pnpm run build` para generar un paquete estático optimizado listo para producción.
</Callout>
```

## 2. Imágenes Inteligentes Sensibles al Tema

El componente `<Image />` de Boltdocs te permite definir imágenes que cambian dinámicamente según el tema seleccionado (Claro/Oscuro) por el usuario. Solo necesitas proporcionar el atributo `theme`.

```mdx
{/* Imagen visible solo en modo Claro */}
<Image src="/banner-light.webp" alt="Banner de Boltdocs en modo Claro" theme="light" />

{/* Imagen visible solo en modo Oscuro */}
<Image src="/banner-dark.webp" alt="Banner de Boltdocs en modo Oscuro" theme="dark" />
```

### Demostración en Vivo:
Cambia el tema de tu documentación en la barra superior para ver cómo se intercambia el banner automáticamente:

## 3. Tablas Estilizadas

Boltdocs transforma de forma automática cualquier tabla Markdown estándar en una tabla moderna con scroll horizontal responsivo, bordes redondeados y un diseño premium.

| Comando | Acción | Descripción |
| :--- | :--- | :--- |
| `pnpm run dev` | Iniciar Servidor | Lanza el servidor de desarrollo local con soporte HMR ultrarrápido. |
| `pnpm run build` | Compilar Sitio | Genera los assets estáticos de producción optimizados. |
| `pnpm run test` | Ejecutar Pruebas | Corre la suite de pruebas unitarias con Vitest. |

## 4. Documentación de Propiedades con `<Field>`

Para documentar parámetros, configuraciones de API o propiedades de componentes de forma elegante, utiliza el componente `<Field />`. Soporta los atributos `name`, `type`, `description` y `required`.

```mdx
<Field name="siteUrl" type="string" required description="La URL canónica absoluta de tu sitio de documentación.">
  Se utiliza de forma automática para construir los metadatos SEO y generar el archivo `sitemap.xml`.
</Field>

<Field name="breadcrumbs" type="boolean" defaultValue="true" description="Muestra u oculta los enlaces de navegación jerárquica en la parte superior.">
  Ayuda a los usuarios a ubicarse fácilmente en la jerarquía de las páginas de tu documentación.
</Field>
```

## 5. Bloques de Código con Títulos

Puedes añadir anotaciones a tus bloques de código especificando el título del archivo o lenguaje, logrando pestañas visuales espectaculares:

```ts title="boltdocs.config.ts"
import { defineConfig } from 'boltdocs'

export default defineConfig({
  theme: {
    title: 'Mi Documentación Premium',
    logo: {
      light: '/dark.svg',
      dark: '/light.svg',
      alt: 'Logo de Boltdocs'
    }
  }
})
```

Every Boltdocs site comes with full-text search built in. The search index is assembled **at build time** from your pages' titles, headings, descriptions, and body text. No API key. No external dependency. No runtime overhead.

---

## What Gets Indexed

For each page in your documentation, Boltdocs extracts and indexes:

| Data | Source |
| :--- | :--- |
| Page title | `title` frontmatter or filename |
| Page description | `description` frontmatter or first paragraph |
| All `h2`–`h6` headings | Markdown heading elements |
| Page body | Plain text, stripped of Markdown syntax |

Callouts, code blocks, and table contents are included in the body text. Images are not indexed.

---

## Using Search

A search dialog is triggered by:
- Clicking the **Search** button in the top navigation bar
- Pressing `Cmd+K` (macOS) or `Ctrl+K` (Windows / Linux)

The dialog shows instant results as you type, grouped by page, with highlighted matching text snippets.

<Callout variant="note">
  Search works entirely on the client side using a pre-built index embedded in the page bundle. There is no server round-trip — results are instant even on slow connections.
</Callout>

## Search in Custom Layouts

If you're building a custom layout, you can render the `<SearchDialog>` component exported from `boltdocs`:

```tsx
import { SearchDialog } from 'boltdocs'

export function MyLayout({ children }) {
  return (
    <div>
      <SearchDialog />
      <main>{children}</main>
    </div>
  )
}
```

## `useSearch()` Hook

For building a fully custom search experience, the `useSearch()` hook gives you programmatic access to the search state:

```tsx
import { useSearch } from 'boltdocs'

export function MySearchBar() {
  const { query, setQuery, results, isOpen, open, close } = useSearch()

  return (
    <div>
      <input
        value={query}
        onChange={(e) => setQuery(e.target.value)}
        placeholder="Search docs..."
      />
      {isOpen && results.map((result) => (
        <a key={result.path} href={result.path}>
          <strong>{result.title}</strong>
          <span>{result.description}</span>
        </a>
      ))}
    </div>
  )
}
```

### `useSearch()` Return Values

| Property | Type | Description |
| :--- | :--- | :--- |
| **`query`** | `string` | The current search query string. |
| **`setQuery`** | `(q: string) => void` | Update the query and trigger a new search. |
| **`results`** | `SearchResult[]` | Array of matching routes, sorted by relevance. |
| **`isOpen`** | `boolean` | Whether the search dialog is currently visible. |
| **`open`** | `() => void` | Open the search dialog. |
| **`close`** | `() => void` | Close the search dialog and clear the query. |

## Excluding Pages from Search

Pages with `sidebarHidden: true` are still indexed by default. To exclude a page from the search index entirely, set `hidden: true` in its frontmatter:

```md
---
title: Internal Notes
hidden: true
---
```

<Callout variant="tip">
  Use `sidebarHidden: true` to hide a page from navigation while keeping it searchable. Use `hidden: true` to exclude it from both the sidebar and the search index.
</Callout>

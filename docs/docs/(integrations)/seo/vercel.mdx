Vercel provides built-in analytics and real-user monitoring (RUM) for sites deployed on their platform. Boltdocs injects the required scripts automatically when you enable them in your configuration.


## Configuration Reference

| Property | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| **`analytics`** | `boolean` | `true` | Enables Vercel Web Analytics (page views, unique visitors). |
| **`speedInsights`** | `boolean` | `true` | Enables Vercel Speed Insights (Core Web Vitals, LCP, CLS, INP). |

### Minimal Example

```ts
integrations: {
  analytics: {
    vercel: {
      analytics: true,
    },
  },
}
```

### Both Enabled (Default)

```ts
integrations: {
  analytics: {
    vercel: {
      analytics: true,
      speedInsights: true,
    },
  },
}
```

---

## How It Works

When enabled, Boltdocs injects two script fragments into the `<head>` of every page at build time:

1. **Vercel Analytics** — `<script defer src="/_vercel/insights/script.js">`
2. **Speed Insights** — `<script defer src="/_vercel/speed-insights/script.js">`

Vercel automatically handles the data collection pipeline on their edge network. No additional API keys or configuration required.

---

## Troubleshooting

### Scripts don't appear in development

This is expected. Both scripts are only injected in production builds. Run `boltdocs build && boltdocs preview` to test locally.

### Data doesn't appear in the Vercel dashboard

- Make sure your project is deployed to the Vercel production environment
- Verify the scripts are present by viewing the page source of your deployed site
- Wait up to 24 hours for data to appear in the dashboard

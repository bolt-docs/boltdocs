# API Reference

The `ApiReference` component (formerly `ComponentProps`) is a high-performance, aesthetically pleasing UI element designed specifically for documenting component APIs. It provides a structured, interactive grid layout that makes properties, types, and default values incredibly easy to scan, search, and read.

## Overview

By default, `<ApiReference>` organizes and styles your component parameters with modern pill shapes and beautiful design tokens:

<ApiReference
  title="Button Property Reference"
  props={[
    {
      name: "variant",
      type: "'primary' | 'secondary' | 'outline' | 'ghost' | 'danger' | 'success' | 'warning' | 'info' | 'subtle' | 'link'",
      defaultValue: "'primary'",
      description: "The visual style variant of the button."
    },
    {
      name: "size",
      type: "'sm' | 'md' | 'lg'",
      defaultValue: "'md'",
      description: "The physical size and padding scale."
    },
    {
      name: "disabled",
      type: "boolean",
      defaultValue: "false",
      description: "When true, disables all interactions."
    }
  ]}
/>

## Interactive Search & Filtering

You can enable an elegant, real-time search bar by passing the `searchable={true}` prop. This allows users to search properties instantly by name, type, or description words—especially useful for components with extensive APIs:

<ApiReference
  title="ApiReference Property Reference"
  searchable={true}
  props={[
    {
      name: "title",
      type: "string",
      description: "Optional. A heading displayed above the properties table."
    },
    {
      name: "props",
      type: "PropItem[]",
      required: true,
      description: "An array of objects defining each property (name, type, description, etc)."
    },
    {
      name: "searchable",
      type: "boolean",
      defaultValue: "false",
      description: "When true, renders a premium real-time filter bar on top."
    },
    {
      name: "variant",
      type: '"default" | "bordered" | "ghost" | "card"',
      defaultValue: '"bordered"',
      description: "The visual style variant of the ApiReference container."
    },
    {
      name: "className",
      type: "string",
      description: "Custom classes to append to the wrapper container."
    }
  ]}
/>

Specify the `variant` prop to customize the visual structure of your API reference tables.

  ]}

<ApiReference

## Features

### 1. Smart Union Type Parsing
When a property type is a union of literal strings (e.g. `'primary' | 'secondary' | 'danger'`), the component automatically parses and renders them as individual, highly-readable inline pill badges, instead of a raw unformatted text block.

### 2. Copy-to-Clipboard
Hovering over any property name displays a subtle copy icon. Clicking the icon copies the exact property name instantly with neat visual confirmation.

### 3. Mobile Card Layout
Large tables are notoriously difficult to read on mobile. The `ApiReference` component automatically transitions into a gorgeous card-based listing on small viewports, ensuring a premium reading experience on any device.

## PropItem Definition

Each object in the `props` array should follow this interface:

<ApiReference
  props={[
    {
      name: "name",
      type: "string",
      required: true,
      description: "The name of the property."
    },
    {
      name: "type",
      type: "string",
      required: true,
      description: "The data type string or union (e.g., 'boolean', 'string')."
    },
    {
      name: "defaultValue",
      type: "string",
      description: "The value used if the property is omitted."
    },
    {
      name: "required",
      type: "boolean",
      defaultValue: "false",
      description: "If true, displays a red '*' or badge next to the name."
    },
    {
      name: "description",
      type: "ReactNode",
      required: true,
      description: "A detailed explanation of the property's role."
    }
  ]}
/>

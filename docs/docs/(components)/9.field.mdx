# Field

The Field component is designed to provide a structured way to document individual API properties, configuration options, or any specific data field. 

<Warning>
  **Legacy Status**: While `<Field />` is fully supported, we recommend using the new, more structured `<ApiReference /` component for documenting complete sets of props in a table format.
</Warning>

## Overview

<Field 
  name="siteUrl" 
  type="string" 
  required
  defaultValue='"https://boltdocs.dev"'
>
  The base URL of your documentation site. It is primarily used for generating canonical URLs and absolute paths in your sitemap.
</Field>

## Variants & Examples

### Visual Style Variants

Boltdocs supports four beautiful visual variants for Fields. Specify the `variant` prop to change the styling.

#### Card Variant (Default)
<Field name="siteUrl" type="string" variant="card" defaultValue='"https://boltdocs.dev"'>
  The elevated, glassmorphic card look with rich interactive highlights.
</Field>

#### Bordered Variant
<Field name="siteUrl" type="string" variant="bordered" defaultValue='"https://boltdocs.dev"'>
  A clean transparent style with high definition border outlining.
</Field>

#### Ghost Variant
<Field name="siteUrl" type="string" variant="ghost" defaultValue='"https://boltdocs.dev"'>
  A minimal borderless layout with subtle background highlighting on hover.
</Field>

#### Default Variant
<Field name="siteUrl" type="string" variant="default" defaultValue='"https://boltdocs.dev"'>
  A line-divider layout perfect for clean stacked lists of fields.
</Field>

### Basic Usage

Use `<Field>` for standalone definitions where a full table might be unnecessary.

<Field name="title" type="string">
  The title text displayed in the navigation bar.
</Field>

### Complex Types

Fields can document complex configuration objects by using the `type` prop for interface names.

<Field 
  name="themeConfig" 
  type="BoltdocsThemeConfig" 
  required
>
  The central configuration object defining the visual style and navigation structure of your site.
</Field>

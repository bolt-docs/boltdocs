# Cards

Cards are versatile content blocks used to highlight features, project goals, or organized directory links. They are designed to work in a responsive grid layout using the `<Cards>` container.

## Variants & Examples

### Visual Style Variants

Boltdocs supports four beautiful visual variants for Cards. Specify the `variant` prop to customize the look.

#### Card Variant (Default)
<Cards cols={2}>
  <Card title="Card Style" icon={<Zap />} variant="card">
    The classic elevated card styling with subtle gradients and spotlight effects.
  </Card>
</Cards>

#### Bordered Variant
<Cards cols={2}>
  <Card title="Bordered Style" icon={<Palette />} variant="bordered">
    A transparent background with a continuous border that highlights on hover.
  </Card>
</Cards>

#### Ghost Variant
<Cards cols={2}>
  <Card title="Ghost Style" icon={<Star />} variant="ghost">
    A minimal, borderless design that displays a soft background hover effect.
  </Card>
</Cards>

#### Default Variant
<Cards cols={1}>
  <Card title="Default Style" icon={<Rocket />} variant="default">
    A clean, streamlined layout resembling a list item with simple bottom dividers.
  </Card>
</Cards>

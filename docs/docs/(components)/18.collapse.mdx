# Collapse

The Collapse component is an interactive panel that can be expanded or collapsed to organize and hide secondary content. It supports individual controlled/uncontrolled state as well as grouped accordion behavior.

## Overview

<div className="space-y-4 my-6">
  <Collapse title="What is Boltdocs?" variant="card" defaultOpen={true} icon={<HelpCircle />}>
    Boltdocs is a lightweight documentation generator built on React, Vite, and Turborepo. It focuses on lightning-fast speed, premium visual aesthetics, and powerful MDX extensibility out of the box.
  </Collapse>

  <Collapse title="Is it fully customizable?" variant="card" icon={<Settings />}>

</div>

## Variants & Examples

### Visual Variants

Boltdocs offers four pre-styled variants out of the box to seamlessly fit into any part of your documentation.

#### 1. Default (Underlined)

The `default` variant features a minimal, borderless layout with a clean dividing line. It's ideal for inline lists and FAQ sections.

<Collapse title="Default Variant Example" variant="default" defaultOpen={true}>
  This is the default collapse variant. It uses simple dividing lines to keep the design clean and lightweight.
</Collapse>

#### 2. Bordered

The `bordered` variant wraps the entire component with a subtle outline, highlighting it as a distinct block of information.

<Collapse title="Bordered Variant Example" variant="bordered">
  The bordered variant is excellent when you want to group complex content blocks or isolate collapsible sections.
</Collapse>

#### 3. Ghost

The `ghost` variant is completely unbordered with an elegant, responsive hover background.

<Collapse title="Ghost Variant Example" variant="ghost">
  The ghost variant offers maximum minimalism, blending naturally with paragraphs and lists.
</Collapse>

#### 4. Card

The `card` variant applies a rich card-like look with a elevated surface background (`bg-surface`) and subtle shadows.

<Collapse title="Card Variant Example" variant="card" icon={<Sparkles />}>
  The card variant provides the most premium feel and is perfect for highlighting featured FAQs, troubleshooting steps, or key callouts.
</Collapse>

### Accordion Mode (`CollapseGroup`)

By wrapping multiple `<Collapse>` panels inside a `<CollapseGroup>` with `accordion={true}`, you can create a high-fidelity Accordion where expanding one panel automatically collapses the others.

<CollapseGroup accordion={true} defaultOpenId="sec-1">
  <Collapse id="sec-1" title="Section 1: Core Concepts" variant="bordered" icon={<HelpCircle />}>
    Understand the foundational structure of Boltdocs, including MDX compilation, Turborepo orchestration, and the client-side single page app routing.
  </Collapse>
  <Collapse id="sec-2" title="Section 2: Advanced Integrations" variant="bordered" icon={<Sparkles />}>
    Extend your documentation with third-party tracking like Google Analytics 4, Mermaid diagrams, KaTeX formulas, and custom layout overrides.
  </Collapse>
  <Collapse id="sec-3" title="Section 3: Security & Performance" variant="bordered" icon={<ShieldAlert />}>
    Explore best practices for keeping your static sites secure, including DOM purification, and optimizing builds with pre-compiled asset caching.
  </Collapse>
</CollapseGroup>

```mdx title="accordion-example.mdx"
import { HelpCircle, Sparkles, ShieldAlert } from 'lucide-react'

<CollapseGroup accordion={true} defaultOpenId="sec-1">
  <Collapse id="sec-1" title="Section 1: Core Concepts" variant="bordered" icon={<HelpCircle />}>
    Understand the foundational structure of Boltdocs...
  </Collapse>
  <Collapse id="sec-2" title="Section 2: Advanced Integrations" variant="bordered" icon={<Sparkles />}>
    Extend your documentation with third-party tracking...
  </Collapse>
  <Collapse id="sec-3" title="Section 3: Security & Performance" variant="bordered" icon={<ShieldAlert />}>
    Explore best practices for keeping your static sites secure...
  </Collapse>
</CollapseGroup>
```

<Tip>
  Set custom IDs on each `<Collapse>` inside a `<CollapseGroup>` to ensure consistent uncontrolled default routing and stable hydration.
</Tip>

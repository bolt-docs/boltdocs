# Image

Themed image component for documentation with light/dark support.

```tsx
import { Image } from 'boltdocs/client'
```

## Variants & Examples

### Theme-Switching Images

By placing two `<Image>` components with different `theme` values back-to-back, you can create a single "logical" image that adapts to the user's theme.

<Image src="https://placehold.co/600x200/F4F4F4/1e1e1e?text=Themed+Creative" theme="light" alt="Light Asset" />
<Image src="https://placehold.co/600x200/1e1e1e/white?text=Themed+Creative" theme="dark" alt="Dark Asset" />

### Basic Usage

Standard Markdown `![]()` works perfectly in Boltdocs for global images. Use the `<Image>` component specifically when you need theme-awareness or advanced React logic.

<Image src="https://placehold.co/600x200?text=Global+Image" alt="Global Content" />

### Rich Captions & Zoom Lightbox

The `<Image>` component supports interactive zooms and descriptive captions with full Markdown support:

<Image
  src="https://placehold.co/600x250/5468ff/ffffff?text=Interactive+Zoom+Demo"
  alt="Interactive Zoom Demo"
  zoom={true}
  caption={<span>This is a **rich caption** supporting bold text and interactive <a>links</a>. Click the image to open the premium fullscreen lightbox zoom.</span>}
/>

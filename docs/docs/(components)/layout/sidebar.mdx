The `Sidebar` component displays the site directory structure, listing nested folders, page paths, category headers, and navigation badges.

---

## Import

```tsx
import { Sidebar } from 'boltdocs/primitives'
```

---

## Composable Sidebar Example

The unstyled primitive `Sidebar` is designed to be assembled using composable blocks. The example below shows how to build a responsive custom sidebar using the primitive containers and the automated routing hook:

```tsx
// docs/components/CustomSidebar.tsx
import React from 'react'
import { Sidebar } from 'boltdocs/primitives'
import { useRoutes } from 'boltdocs/client'

export default function CustomSidebar() {
  const { routes } = useRoutes()

  return (
    <>
      {/* 1. Desktop Sidebar Container */}
      <Sidebar className="hidden lg:flex border-r border-subtle bg-zinc-50 dark:bg-zinc-950">
        <Sidebar.Header className="px-4 py-3 flex items-center justify-between border-b">
          <span className="text-xs font-bold uppercase tracking-wider text-muted">Navigation</span>
        </Sidebar.Header>
        <Sidebar.Content>
          {/* Automatically handles collapsible nested routes and group headers */}
          <Sidebar.Items routes={routes} />
        </Sidebar.Content>
      </Sidebar>

      {/* 2. Responsive Mobile Drawer Container */}
      <Sidebar.Mobile className="bg-zinc-50 dark:bg-zinc-950">
        <Sidebar.Header className="px-4 py-3 flex items-center justify-between border-b">
          <span className="text-xs font-bold uppercase tracking-wider text-muted">Menu</span>
        </Sidebar.Header>
        <Sidebar.Content>
          <Sidebar.Items routes={routes} />
        </Sidebar.Content>
      </Sidebar.Mobile>
    </>
  )
}
```

## Real-World Production Reference

Below is a complete, production-ready reference implementation demonstrating how to build a fully featured sidebar navigation system (similar to the built-in theme sidebar). It integrates logo branding, mobile sidebar closing controls, desktop vs. mobile structures, and combines versioning and translation drop-downs inside the mobile menu drawer:

```tsx
// docs/components/ProductionSidebar.tsx
import React from 'react'
import { Sidebar, Button, Menu } from 'boltdocs/primitives'
import { useRoutes, useNavbar, useUI, useVersion, useI18n } from 'boltdocs/client'
import { X, ChevronDown, Languages } from 'lucide-react'

export default function ProductionSidebar() {
  const { routes, config } = useRoutes()
  const { logo, title, logoProps } = useNavbar()
  const { closeSidebar } = useUI()

  const { currentVersionLabel, availableVersions, handleVersionChange } = useVersion()
  const { currentLocale, availableLocales, handleLocaleChange } = useI18n()

  const SidebarLogo = logo ? (
    <img
      src={logo}
      alt={logoProps?.alt || title}
      width={24}
      height={24}
      className="rounded-lg"
    />
  ) : null

  // 1. Version Switcher Selector for Mobile Layouts
  const MobileVersionSelector = availableVersions.length > 0 && (
    <select
      value={availableVersions.find(v => v.isCurrent)?.value}
      onChange={(e) => handleVersionChange(e.target.value)}
      className="flex-1 bg-surface border border-subtle rounded-lg px-3 py-2 text-xs font-semibold"
    >
      {availableVersions.map(v => (
        <option key={v.key} value={v.value}>{v.label}</option>
      ))}
    </select>
  )

  // 2. Language Selector for Mobile Layouts
  const MobileLocaleSelector = availableLocales.length > 0 && (
    <select
      value={currentLocale}
      onChange={(e) => handleLocaleChange(e.target.value)}
      className="flex-1 bg-surface border border-subtle rounded-lg px-3 py-2 text-xs font-semibold"
    >
      {availableLocales.map(loc => (
        <option key={loc.key} value={loc.value}>{loc.label}</option>
      ))}
    </select>
  )

  const hasMobileSelectors = availableVersions.length > 0 || availableLocales.length > 0

  return (
    <>
      {/* A. Desktop Sidebar Panel */}
      <Sidebar className="hidden lg:flex border-r border-subtle bg-main">
        <Sidebar.Content>
          <Sidebar.Items routes={routes} />
        </Sidebar.Content>
      </Sidebar>

      {/* B. Mobile Drawer Panel */}
      <Sidebar.Mobile className="bg-main">
        <Sidebar.Header className="flex items-center justify-between border-b border-subtle px-4 py-3">
          <div className="flex items-center gap-3">
            {SidebarLogo}
            <span className="font-bold text-base text-body truncate max-w-[140px]">
              {title}
            </span>
          </div>
          
          <Button
            onPress={closeSidebar}
            className="h-8 w-8 flex items-center justify-center text-muted hover:text-body rounded-lg hover:bg-surface transition-colors"
          >
            <X size={18} />
          </Button>
        </Sidebar.Header>

        <Sidebar.Content className="p-4">
          {/* Version/Language dropdowns embedded inside mobile drawer */}
          {hasMobileSelectors && (
            <div className="flex flex-col gap-3 mb-6">
              <div className="flex gap-2">
                {MobileVersionSelector}
                {MobileLocaleSelector}
              </div>
              <div className="border-b border-subtle my-2" />
            </div>
          )}

          <Sidebar.Items routes={routes} />
        </Sidebar.Content>
      </Sidebar.Mobile>
    </>
  )
}
```

## Composable Sub-Components

The `Sidebar` primitive provides the following sub-components for structure customization:

| Component | HTML Tag | Description | Props |
| :--- | :--- | :--- | :--- |
| **`Sidebar.Root`** / **`Sidebar`** | `<aside>` | The main desktop sidebar outer container. | [`ComponentBaseProps`](#componentbaseprops-common) |
| **`Sidebar.Mobile`** | `<div>` (Modal) | Mobile sidebar drawer container using accessible overlays. | [`ComponentBaseProps`](#componentbaseprops-common) |
| **`Sidebar.Header`** | `<div>` | Upper padding section container (ideal for logos, search inputs, or headers). | [`ComponentBaseProps`](#componentbaseprops-common) |
| **`Sidebar.Content`** | `<div>` | Scrollable navigation list wrapper that maintains scroll positions. | [`ComponentBaseProps`](#componentbaseprops-common) |
| **`Sidebar.Group`** | `<div>` | Groups a set of related navigation links under a common title. | [`Sidebar.Group Props`](#sidebargroup-props) |
| **`Sidebar.Link`** | `<a>` | An optimized navigation link to a specific page route. | [`Sidebar.Link Props`](#sidebarlink-props) |
| **`Sidebar.SubGroup`** | `<div>` | A collapsible section container for nested sub-routes. | [`Sidebar.SubGroup Props`](#sidebarsubgroup-props) |
| **`Sidebar.Item`** | Varies | Recursive router mapping utility rendering links or subgroups automatically. | [`Sidebar.Item Props`](#sidebaritem-props) |
| **`Sidebar.Items`** | Varies | Automated loop container that maps and renders a route collection. | [`Sidebar.Items Props`](#sidebaritems-props) |

## Component Props

### ComponentBaseProps (Common)

| Property | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| **`children`** | `ReactNode` | `undefined` | Children content elements. |
| **`className`** | `string` | `undefined` | Custom CSS utility classes. |
| **`style`** | `CSSProperties` | `undefined` | Inline style settings. |

### `Sidebar.Group` Props

| Property | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| **`title`** | `string` | `undefined` | Group category title text. |
| **`icon`** | `ElementType` | `undefined` | Custom leading icon component. |
| **`children`** | `ReactNode` | *Required* | Child sidebar elements. |

### `Sidebar.Link` Props

| Property | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| **`label`** | `string` | *Required* | Link display name label. |
| **`href`** | `string` | *Required* | Target destination route path. |
| **`active`** | `boolean` | `false` | Active state style toggle. |
| **`icon`** | `ElementType` | `undefined` | Leading icon element wrapper. |
| **`badge`** | `string \| BadgeConfig` | `undefined` | Notification status badge. |

### `Sidebar.SubGroup` Props

Inherits all [`Sidebar.Link Props`](#sidebarlink-props) plus:

| Property | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| **`isOpen`** | `boolean` | `false` | Collapsed state visibility indicator. |
| **`onToggle`** | `() => void` | `undefined` | Toggle trigger callback handler. |
| **`children`** | `ReactNode` | *Required* | Subgroup navigation links. |

### `Sidebar.Item` Props

| Property | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| **`route`** | `ComponentRoute` | *Required* | Route config object to parse. |
| **`activePath`** | `string` | *Required* | Active window URL pathname. |

### `Sidebar.Items` Props

| Property | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| **`routes`** | `ComponentRoute[]` | *Required* | Array of route configs to render recursively. |

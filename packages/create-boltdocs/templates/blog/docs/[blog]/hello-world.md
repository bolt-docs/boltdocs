# Hello World

This is your first blog post. Collections in Boltdocs let you create blogs, changelogs, or release notes using bracket directories like `[blog]`.

## Why collections?

- Dynamic routes from Markdown files
- Built-in pagination support
- Custom `list.tsx` and `post.tsx` components
- Automatic grouping in the sidebar
